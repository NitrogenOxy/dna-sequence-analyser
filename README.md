# DNA Sequence Analyser


## Overview of current features:
- DNA sequence input + validation
- sequence length calculation
- Nucleotide frequency analysis
- GC content calculation

## Tools:
- Python

## Purpose
This project was made with the aim of developing my Python programming skills and applying them to relevant biological sequence data for analysis

## Possible future improvements:
- Analysis of multiple DNA sequences
- Reverse complement calculation
- DNA transcription + Protein translation
